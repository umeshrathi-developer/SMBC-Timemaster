Expected File Format

Row 2 (Header):

Date Employee Name 1 Employee Name 2 Employee Name 3 ...

Row 3+ (Data):

Date Hours 1 Hours 2 Hours 3 ...
2026-04-01 8 8.5 9 ...
2026-04-02 8 8 ...
2026-04-03 0 8 8 ...

Important Notes:

  • Include all dates from start to end of month (including weekends and holidays)
  • Employee names can include a second-line client ID; the first line must match the system employee name
  • Only entries with hours > 0 will be imported
  • Empty cells or 0 values will be skipped
  • Weekends and holidays can have entries if value > 0
  • All entries will be created in DRAFT status
  • Existing DRAFT entries for the same employee and date will be updated; SUBMITTED entries will be skipped
  • The employee's assigned project is used when available; the Project Name field is used only as a fallback

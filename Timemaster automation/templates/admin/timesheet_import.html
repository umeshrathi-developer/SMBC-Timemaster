File Format Requirements

Your XLSX file should contain the following sheets with these column names:

1. Timesheet Summary

  • Email ID
  • Team Member
  • Project ID
  • Project
  • Total Hours

2. Timesheet Details

  • Email ID
  • Team Member
  • Project ID
  • Project
  • Date (YYYY-MM-DD format)
  • Time Logged
  • Comment

3. Attendance Summary

  • Email ID
  • Team Member
  • Business Hours
  • Available Hours
  • Project Hours

4. Attendance Details

  • Email ID
  • Team Member
  • Date (YYYY-MM-DD format)
  • Business Hours
  • Available Hours
  • Remarks

Import Notes

  • Only administrators can import timesheet data
  • Existing data will be replaced during import
  • Dates should be in YYYY-MM-DD format
  • All numeric fields should be valid numbers
